# SVG Editor

A lightweight, browser-based SVG editor with raster-to-SVG conversion.

## What It Is
- A fast, self-contained tool that runs entirely in the browser
- Focused on creating, editing, and exporting clean SVG graphics

## What It Can Do
- Draw and edit shapes: rectangles, circles, and freehand paths
- Select, move, resize, and style shapes (fill, stroke, stroke width)
- Import PNG/JPEG and convert to SVG using ImageTracer.js
- Control vectorization detail with a Sharpness slider (1–100)
- Use presets (default, posterized, curvy, sharp, detailed, grayscale)
- Export in multiple formats: SVG file, TXT (raw SVG), or HTML (embedded)
- Choose export size: canvas size or fit-to-content with optional padding
- Produce clean exports (grid/background excluded) ready for reuse
- Preview imported raster and see status during vectorization
- Provide clear error feedback if conversion fails
